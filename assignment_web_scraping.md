
## Практическая работа: HTTP-запросы и веб-скрейпинг

### Цель работы

Закрепить навыки отправки HTTP-запросов с помощью библиотеки `requests`, безопасного разбора веб-страниц с использованием `BeautifulSoup` и CSS-селекторов, а также научиться писать отказоустойчивый код с помощью обработки исключений и проверки ответов сервера.

### Инструкция по выполнению

1. Создайте новый блокнот в **Google Colab** или Jupyter Notebook.
2. Выполните в нём три практических задания, приведённых ниже. Код должен быть полностью рабочим, исполненным и подготовленным к возможным сетевым сбоям.
3. Оформите работу с помощью текстовых ячеек Markdown, разделяя задания и добавляя краткие комментарии к коду.
4. Настройте права доступа к блокноту: «Поделиться» → «Общий доступ» → **«Все, у кого есть ссылка»** с правами редактора.

### Условия заданий

#### Задание 1. Работа с API и структурами данных (10 баллов)

Отправьте GET-запрос к API по адресу `https://dog.ceo`. Извлеките названия всех основных пород собак (в ответе API они приходят в виде ключей словаря `message`). Сохраните их в список `titles` и выведите на экран первые 10 названий.

**Обязательное условие:** оберните сетевой запрос в конструкцию `try/except` для перехвата возможных ошибок соединения (`requests.exceptions.RequestException`). В случае сбоя интернета программа не должна аварийно завершаться, а должна выводить текстовое предупреждение.

#### Задание 2. Анализ данных и валидация ответов (10 баллов)

Используя список `titles` из задания 1, посчитайте общее количество извлечённых пород. Выведите результат в виде понятного текстового сообщения, например: «Всего найдено пород собак: X».

**Обязательное условие:** перед обработкой данных добавьте в код явную проверку HTTP-статуса ответа (`response.status_code == 200`) или вызов метода `response.raise_for_status()`. Код должен приступать к разбору JSON только в случае успешного ответа сервера.

#### Задание 3. Сложный парсинг HTML и CSS-селекторы (10 баллов)

Отправьте запрос на страницу `http://httpbin.org`. С помощью **CSS-селекторов** (метод `.select()`) найдите все ссылки на странице и выведите их адреса (атрибуты `href`).

**Обязательные условия:**

1. Для извлечения атрибутов используйте безопасный метод `.get("href")` вместо квадратных скобок, чтобы избежать ошибок, если у тега отсутствует этот атрибут.
2. Реализуйте проверку: если список найденных ссылок пуст, скрипт должен вывести сообщение «Ссылки на странице не обнаружены», а не завершаться без результата.
