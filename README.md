
# AI Notebook Grader

Автоматизированная первичная проверка студенческих Jupyter Notebook с помощью Python и AI-агента в Yandex AI Studio.

## Пример проверяемого задания

В качестве демонстрационного задания используется практическая работа по отправке HTTP-запросов, работе с API, парсингу HTML с помощью BeautifulSoup и обработке сетевых ошибок.

Условие задания и критерии оценивания находятся в файле
[assignment_web_scraping.md](assignment_web_scraping.md).

## Возможности

- Чтение выгрузки Moodle в CSV или Excel.
- Извлечение ссылок на Google Colab и GitHub.
- Загрузка ноутбуков через Google Drive API и GitHub Raw.
- Извлечение Markdown, кода и текстовых outputs.
- Передача содержимого AI-агенту.
- Разбор JSON-ответа.
- Формирование Excel-отчёта.
- Раздельная обработка ошибок загрузки и AI-проверки.

## Архитектура

`Moodle → ссылки → загрузка ноутбуков → разбор ячеек → Yandex AI Studio → JSON → Excel`

## Запуск

1. Откройте `ai_notebook_grader.ipynb` в Google Colab.
2. Запустите ячейку установки библиотек.
3. В Google Colab Secrets добавьте `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` и `AGENT_ID`.
4. Запустите ячейки последовательно.
5. Авторизуйте Google Drive и загрузите выгрузку Moodle.
6. Скачайте сформированный `checked_results.xlsx`.

## Ограничения

Ноутбук студента не исполняется. Анализируются исходный код, Markdown и текстовые outputs, уже сохранённые в ноутбуке. Изображения и бинарные outputs в этой версии не анализируются.

AI-оценка не заменяет преподавательскую экспертизу. Рекомендуется проверять выборку работ вручную и контролировать соответствие оценок критериям.

## Безопасность

Не публикуйте API-ключи, идентификаторы закрытых облачных проектов, персональные данные студентов и непубличные студенческие работы. Для демонстрации используйте синтетические или обезличенные данные.
