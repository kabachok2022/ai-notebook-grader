# ai-notebook-grader
Automated evaluation of student Jupyter Notebooks using Python and Yandex AI Studio
# AI Notebook Grader — автоматизированная проверка студенческих работ с использованием LLM

## О проекте

В рамках преподавательской деятельности разработала прототип системы автоматизированной проверки учебных работ студентов, представленных в формате Jupyter Notebook (Google Colab).

Задача проекта — сократить время преподавателя на первичную проверку программных заданий, автоматизировать анализ кода и результатов его выполнения, а также формировать структурированную обратную связь для студентов.

## Какую проблему решает проект

При проверке практических работ по программированию преподавателю приходится последовательно открывать множество студенческих ноутбуков, изучать код, проверять результаты выполнения и сопоставлять их с критериями оценивания.

Разработанный инструмент объединяет эти операции в единый процесс:

1. Получает список студенческих работ из выгрузки Moodle.
2. Извлекает ссылки на ноутбуки Google Colab и GitHub.
3. Загружает содержимое ноутбуков через Google Drive API или GitHub.
4. Извлекает программный код, текстовые пояснения и сохранённые результаты выполнения.
5. Передаёт содержимое ноутбука AI-агенту на базе Yandex AI Studio для проверки по заданным критериям.
6. Получает структурированную оценку и комментарии.
7. Формирует итоговую Excel-таблицу с результатами проверки.

## Технологический стек

- **Python** — основная логика приложения.
- **Pandas** — чтение и обработка выгрузок Moodle, формирование итоговой таблицы.
- **Google Drive API** — авторизованное получение файлов Google Colab.
- **GitHub** — получение ноутбуков из репозиториев.
- **OpenAI Python SDK** — взаимодействие с API в формате, совместимом с SDK.
- **Yandex AI Studio** — работа с LLM-агентом, анализирующим студенческие работы.
- **JSON** — передача структурированных результатов проверки.
- **OpenPyXL** — формирование Excel-отчёта.

## Архитектура решения

Процесс можно представить в виде последовательности этапов:

`Moodle → извлечение ссылок → загрузка ноутбуков → разбор содержимого → AI-проверка → Excel-отчёт`

Каждый этап реализован отдельными функциями. Это позволяет диагностировать ошибки загрузки, обработки данных и обращения к AI-агенту независимо друг от друга.

## Особенности реализации

**1. Работа с разными источниками данных.**

Реализовано извлечение ссылок на ноутбуки из выгрузки Moodle и поддержка двух источников: Google Colab и GitHub.

**2. Обработка структуры Jupyter Notebook.**

Система различает Markdown- и code-ячейки, извлекает исходный код, текстовые пояснения и сохранённые результаты выполнения. Это позволяет передавать AI-агенту не только программный код, но и контекст выполненной работы.

**3. Интеграция с AI-агентом.**

Для оценки используется агент Yandex AI Studio с заранее заданными критериями. Результат проверки возвращается в структурированном формате JSON: баллы по отдельным заданиям, итоговая оценка и текстовая обратная связь.

**4. Обработка ошибок.**

Предусмотрены отдельные статусы для ситуаций, когда ссылка не найдена, ноутбук не удалось загрузить или AI-проверка завершилась ошибкой. Такие работы не получают автоматически нулевую оценку, а выделяются для повторной или ручной проверки.

**5. Формирование отчётности.**

Итоговые результаты сохраняются в Excel, что позволяет преподавателю просматривать оценки, комментарии и статус обработки каждой работы.

## Результат

Создан работающий прототип автоматизированного конвейера проверки студенческих Jupyter Notebook с использованием LLM.

Проект демонстрирует практические навыки:
- автоматизации рутинных процессов;
- обработки структурированных и неструктурированных данных;
- интеграции внешних API;
- построения многоэтапных Python-приложений;
- разработки сценариев взаимодействия с LLM;
- организации контроля ошибок и формирования отчётности.
